# ANSTAY Villa Ops v0.6

## Database changes
- Villa GPS configuration: latitude, longitude, attendance radius, GPS-required flag.
- Attendance audit: calculated check-in/check-out distance and GPS verification status.
- Employee shift assignment RLS: admin/ops manage; employee reads own schedule.
- Linked-account guard policies for shared reference tables.
- Monthly closures table and month lock workflow.

## Production RPC
- `attendance_check_in`: server timestamp, employee link check, open-shift check, scheduled shift/villa check, optional geofence check.
- `attendance_check_out`: server timestamp and checkout GPS distance.
- `admin_list_employee_accounts`: admin-only account overview.
- `admin_link_employee_account`: admin-only Auth ↔ employee ↔ app role mapping.
- `close_month`: snapshots monthly villa settlement/P&L and locks the month.
- `reopen_month`: admin-only reopening.

## Safety choices
Villa coordinates are intentionally left blank until an authorized operator captures the actual GPS at each property. Geofence enforcement is off by default. No month is closed automatically.
