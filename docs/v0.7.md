# ANSTAY v0.7

- Added versioned Integration Gateway under `/api/v1`.
- Added server-to-server API key seal. No integration secret is committed.
- Added catalog, stay availability and 93-day ARI availability/inventory endpoints.
- Added idempotent external reservation create/update/cancel endpoints using existing ANSTAY booking core.
- Added normalized webhook ingress for future OTA-specific adapters.
- Added secret-token iCal export per villa without guest PII in calendar summary.
- Added OpenAPI contract at `/api/openapi.json`.
- Rates are intentionally `null` in ARI until ANSTAY pricing rules are configured; the gateway does not invent prices.
